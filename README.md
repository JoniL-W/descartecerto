# DescarteCerto - Flutter - Etapa 1

Protótipo acadêmico para a disciplina Desenvolvimento para Plataformas Móveis (UNIDAVI).

## Rodar no VS Code (Windows)

1. Instale Flutter e Git, verifique `flutter doctor`.
2. No terminal, dentro desta pasta, execute `flutter create --platforms=android,web .` para gerar arquivos de plataforma que não estão no pacote.
3. Execute `flutter pub get`.
4. Execute `flutter run -d chrome`.
5. Para a entrega, capture telas reais da aplicação e envie ao Classroom.

**Importante:** Os pontos apresentados são exemplos fictícios para demonstrar a interface, não locais de descarte reais.

## Funcionalidades da versão 0.1

- Tela inicial e navegação inferior
- Categorias: eletrônicos, pilhas, óleo e móveis
- Listagem e busca textual
- Filtro por categoria
- Detalhes de ponto de coleta fictício
- Tela informativa
